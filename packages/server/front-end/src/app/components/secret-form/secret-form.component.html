Sobre os Segredos de API
Segurança

O valor do segredo é gerado automaticamente usando criptografia segura (64 caracteres hexadecimais).

Como usar

Use o header X-API-Secret com o valor do segredo para acessar:

  • GET /api/projects/{{projectId}}/keys
  • GET /api/folders/{folderId}/keys
Importante

O valor do segredo só é mostrado uma vez, na criação. Guarde-o em local seguro.

Edição

Apenas a descrição pode ser editada. O nome e valor do segredo são imutáveis.
