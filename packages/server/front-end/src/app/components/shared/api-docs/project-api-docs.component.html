API de Projeto vs API de Pasta
API de Projeto
  • Retorna: Todas as chaves de todas as pastas
  • Organização: Por nome da pasta
  • Uso: Configuração geral da aplicação
  • Vantagem: Uma única requisição para tudo
API de Pasta
  • Retorna: Apenas chaves da pasta específica
  • Organização: Chave-valor diretamente
  • Uso: Configuração específica por ambiente
  • Vantagem: Menor transferência de dados
Notas Importantes
  • Segurança: Mantenha seus segredos de API em segurança. Nunca os exponha em código cliente ou repositórios públicos.
  • Performance: Esta API retorna todas as chaves do projeto. Para aplicações com muitas chaves, considere usar a API de pasta específica.
  • Estrutura: A resposta é organizada por nome da pasta, facilitando a separação de ambientes (desenvolvimento, produção, etc.).
  • Cache: As respostas podem ser cachadas por até 5 minutos. Para obter dados sempre atualizados, considere implementar um mecanismo de invalidação de cache.
  • CORS: Esta API suporta CORS e pode ser chamada diretamente do navegador.
