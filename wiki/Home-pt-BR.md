# ConfDrive

[English](https://github.com/rubensflinco/conf-drive/wiki) | [Português (Brasil)](https://github.com/rubensflinco/conf-drive/wiki/Home-pt-BR)

O ConfDrive ajuda quem desenvolve aplicações a gerenciar configurações de projetos em um só lugar e consultá-las por meio de uma API. Um projeto pode agrupar configurações em pastas, como ambientes. O SDK TypeScript oferece cache local e atualização de cache.

## Antes de começar

- O pacote `@conf-drive/sdk` **ainda não foi publicado no npm**. Consulte a [página do pacote no npm](https://www.npmjs.com/package/@conf-drive/sdk); a instalação pelo npm não está disponível até o primeiro release.
- O ConfDrive não oferece uma API hospedada. Você precisa executar ou hospedar o servidor e a interface de gerenciamento, além de criar um projeto, configurações e um segredo de API.
- Mantenha segredos privilegiados em código confiável no servidor. Não os inclua em um bundle público de navegador.
