# ConfDrive

ConfDrive is an open-source configuration management project for Node.js applications. It includes a TypeScript SDK and an API with an Angular management interface for project settings, keys, secrets, and cache invalidation.

## Guides

- [Architecture](Architecture)
- [SDK quickstart](SDK-Quickstart)
- [Development and releases](Development-and-Releases)

The `@conf-drive/sdk` package is the only workspace configured for automatic public npm releases. The server is not deployed automatically; production deployment requires a separately chosen hosting and persistence platform.
