# ConfDrive

[English](https://github.com/rubensflinco/conf-drive/wiki) | [Português (Brasil)](https://github.com/rubensflinco/conf-drive/wiki/Home-pt-BR)

ConfDrive helps application developers manage project settings in one place and read them through an API. A project can group settings into folders, such as environments. The TypeScript SDK provides local caching and cache refresh support.

## Before you start

- The `@conf-drive/sdk` package is **not published to npm yet**. Check the [npm package page](https://www.npmjs.com/package/@conf-drive/sdk); installing with npm is unavailable until its first release.
- ConfDrive does not provide a hosted API. You must run or deploy the server and management interface yourself and create a project, settings, and API secret.
- Keep privileged API secrets on trusted server-side code. Do not put them in a public browser bundle.
